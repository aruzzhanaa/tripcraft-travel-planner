# TripCraft — Travel Planning Platform

## 1. Описание проекта

TripCraft — веб-приложение для планирования путешествий. Оно позволяет пользователям создавать поездки, сохранять информацию о местах для посещения и организовывать маршрут по дням.

Проект разрабатывается в рамках практических занятий по Frontend и Backend.

## 2. Цель проекта

Создать удобную платформу, которая помогает пользователям планировать путешествия, организовывать маршрут и контролировать расходы на поездку.

## 3. Целевая аудитория

- Люди, которые самостоятельно планируют путешествия.
- Туристы, желающие организовать маршрут заранее.
- Друзья и семьи, планирующие совместные поездки.

## 4. Основные функциональные требования

### 4.1. Управление поездками
- Создание новой поездки.
- Указание названия, направления и дат путешествия.
- Просмотр списка поездок.
- Редактирование и удаление поездок.

### 4.2. Планирование маршрута
- Добавление мест для посещения.
- Разделение маршрута по дням.
- Указание названия и описания места.
- Изменение порядка посещения мест.

### 4.3. Управление бюджетом
- Указание предполагаемого бюджета.
- Добавление расходов на транспорт, питание, проживание и развлечения.
- Просмотр общей суммы расходов.

### 4.4. Пользовательский интерфейс
- Главная страница с информацией о сервисе.
- Страница со списком поездок.
- Страница подробного плана поездки.
- Адаптивный дизайн для компьютеров и мобильных устройств.

### 4.5. Backend и хранение данных
- Создание API для управления поездками.
- Сохранение информации о путешествиях и маршрутах.
- Подключение базы данных.
- Проверка входящих данных и обработка ошибок.

### 4.6. Дополнительные функции в будущем
### 4.6. Дополнительные функции в будущем

- **Регистрация и авторизация пользователей** — создание аккаунта, вход в систему и управление личными данными пользователя.
- **Интерактивная карта** — отображение городов, достопримечательностей, кафе, отелей и других точек маршрута на карте.
- **Совместное планирование путешествий** — возможность приглашать друзей в путешествие по ссылке или коду, совместно добавлять интересные места, редактировать маршрут и просматривать общий план поездки.
- **Управление участниками путешествия** — просмотр списка участников, назначение организатора и управление доступом к редактированию поездки.
- **Поиск интересных мест** — поиск достопримечательностей, ресторанов, кафе, музеев и других мест по названию, городу или категории.
- **Избранные места** — сохранение интересных мест в избранное для последующего добавления в маршрут.
- **Голосование за места** — возможность участникам путешествия голосовать за достопримечательности и места, которые они хотят посетить.
- **Расширенное управление бюджетом** — разделение расходов между участниками, просмотр общих затрат и расчёт примерной суммы на одного человека.
- **Экспорт маршрута** — возможность скачать план путешествия в формате PDF или распечатать его для использования без доступа к сайту.
- **Уведомления** — информирование участников об изменениях маршрута, добавлении новых мест и обновлении расходов.
- **Многоязычный интерфейс** — поддержка русского, казахского и английского языков.

После запуска приложение будет доступно по адресу http://localhost:3000.
